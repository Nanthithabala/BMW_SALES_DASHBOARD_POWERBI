# BMW Sales Dashboard - Power BI

## Project Overview
This Power BI dashboard provides a comprehensive analysis of BMW sales performance. The dashboard helps track revenue, sales trends, vehicle model performance, and key business KPIs through interactive visualizations.

## Key Features
- Revenue Analysis
- Sales Trend Analysis
- Top Performing BMW Models
- KPI Cards
- Interactive Filters and Slicers
- Regional Performance Insights

## Tools Used
- Power BI
- DAX
- Power Query
- Excel

## Skills Demonstrated
- Data Cleaning
- Data Modeling
- Data Visualization
- Dashboard Design
- Business Intelligence Reporting
