# AmazonMart Sales Dashboard - Power BI

## Project Overview
This Power BI dashboard provides a comprehensive analysis of AmazonMart sales data from 2011 to 2014. The dashboard helps track sales, profit, orders, and quantity metrics while uncovering regional performance, shipping trends, and category-level insights through interactive visualizations.

## Key Features
- Sales Performance Analysis
- Profit Analysis by Country
- Category & Sub-Category Insights
- Regional Sales Comparison
- Ship Mode Distribution Analysis
- Year-over-Year Sales Trends
- KPI Cards for Sales, Profit, Orders, and Quantity
- Interactive Filters and Slicers

## Key Metrics
- Total Sales: 2M+
- Total Profit: 283K+
- Total Orders: 4K+
- Total Quantity Sold: 30K+
